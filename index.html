Sinkronisasi Cloud
Simpan data ke cloud agar bisa dibuka di perangkat lain. Gratis, tanpa install, tanpa daftar.
1. Aktifkan di perangkat utama

Klik "Aktifkan Sinkron Cloud" untuk membuat kode unik. Data otomatis diunggah setiap ada perubahan.

2. Salin kode sinkron

Kode akan muncul di bawah. Salin dan simpan — ini adalah "kunci" untuk membuka data di perangkat lain.

3. Buka di perangkat lain

Buka file ini di HP / laptop lain, masuk ke menu Sinkronisasi, lalu tempel kode. Data langsung dimuat.
